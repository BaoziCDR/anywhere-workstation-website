# 文件传输

文件通过工作站中的普通 `workstation` 账号传输。下载时使用系统的保存选择器，由你决定保存位置。

## 快速传输

在“设置 → 快捷键”中录入“快速传输文件”的全局快捷键后，按下快捷键会把剪贴板中的**单个普通文件或截图**传到当前选中工作站的家目录：

- 触发时就锁定目标工作站，普通文件不限类型。
- 应用窗口收起时仍可使用；退出 GUI 后停止监听。
- 不会覆盖同名文件。
- 成功后自动复制文件路径，并在菜单栏图标下显示自动消失的气泡。
- 传输期间如果剪贴板已经变化，会保留新的剪贴板内容，可以到任务中心复制路径。
- 失败或取消时，应用创建的临时图片会被清理，你的源文件保留不动。

::: info
文件页已不再提供“粘贴图片”按钮，请使用快速传输快捷键。
:::
