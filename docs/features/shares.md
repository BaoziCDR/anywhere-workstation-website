# 共享目录

新工作站默认不共享 Mac 目录。

## 添加共享

在“文件 → 共享目录”中选择：

1. Mac 上的来源目录；
2. 工作站中的目标目录（必须是空目录或新目录）；
3. 只读或读写权限。

启用热挂载后，工作站运行时也可以添加、编辑和移除共享：停止时保存配置，启动后自动挂载。**移除共享不会删除两端的文件。**

## 旧工作站启用热挂载

先在“维护与恢复”中把 Runtime 和 Agent 更新到支持热挂载的版本，再到共享目录页启用。首次启用需要停机启动一次，之后日常共享操作不用再重启。

如果提示目录被占用，关闭相关文件或终端后，到任务中心继续。

## 需要重新授权

共享显示“需要重新授权”时：

1. 点击该目录的“重新授权”；
2. 重新选择原来的 Mac 目录并确认。

未启用热挂载时，需要先停止工作站。原挂载路径和读写权限会保留，正常重启 Mac 不需要重复授权。目录暂时无法访问时，先检查磁盘是否挂载以及访问权限。
