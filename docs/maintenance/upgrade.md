# 组件更新

App、Runtime、Agent 分层维护，版本只向前升级或做同版本修复。

- **Agent** 只维护自身程序及已安装桌面的受管组件。
- **Chrome** 首次安装官方当前稳定版，之后交由系统自动更新。
- **备份恢复**是独立的数据操作，与组件更新无关。

## 组件状态

“维护与恢复”中每台工作站有一张“组件状态”卡片，显示汇总状态和检查更新入口。工作站运行中有待生效的 Runtime 时，可以确认后点击“重启虚拟机并更新”。

版本详情、手动应用、完整备份预检和救援操作放在默认折叠的“高级”中。

“设置”中的“自动更新组件”即时生效；关闭后只影响之后的自动准备和应用。
